# ⚡ INSTANT START

## 1 Command Setup

```bash
cd autonomous-agent && ./setup.sh
```

**Done!** Browser akan otomatis terbuka di http://localhost:3000

---

## 📋 What Happens

```
[1/5] Checking dependencies...
[2/5] Installing Docker (if needed)...
[3/5] Installing Node.js (if needed)...
[4/5] Building containers...
[5/5] Pulling AI model (~7.5GB)...

✅ All done! Opening browser...
```

**Duration:** 15-45 minutes (first time)

## 🎮 After Setup

```bash
# Start (if stopped)
./quick-start.sh

./stop.sh

./status.sh

./logs.sh

./test.sh
```

## 🆘 Quick Troubleshooting

```bash
# Check what's wrong
./status.sh

./logs.sh

# Restart everything
./stop.sh && ./quick-start.sh

# Pull model manually
./pull-model.sh
```
